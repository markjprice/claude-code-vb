# To-Do List

## User and problem

You, when you want to jot down small tasks and check them off during the day, without opening a separate app just to track them.

## Smallest useful version

Add a task from the terminal, list every task with its status, and mark a task done.

## Acceptance criteria

- Running the tool with an add command and a task description saves that task to a list
- Running the tool with a list command shows every saved task, with completed tasks clearly marked apart from open ones
- Running the tool with a done command and a task's number marks that specific task complete, leaving the rest unchanged

## Non-goals

- Due dates or reminders
- Syncing the list across more than one device
- Permanently deleting a task, rather than marking it done
