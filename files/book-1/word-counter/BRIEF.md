# Word Counter

## User and problem

You, when you want to know how long a piece of writing actually is, words, sentences, and characters, without opening it in a word processor just to check.

## Smallest useful version

Given a text file, report its word count, sentence count, and character count.

## Acceptance criteria

- Given a `.txt` file, reports the total number of words, sentences, and characters
- Given a file containing a single word and no punctuation, still reports 1 word and 1 sentence, not an error
- Given an empty file, reports 0 for every count instead of crashing

## Non-goals

- Reading file formats other than `.txt`
- Reporting reading level or estimated reading time
- A graphical interface
