## 1. Visitors and their one action

- A first-time visitor deciding whether to try HabitTrail. Action: understand what the app does and start using it.
- An existing user who needs help with something, such as setting a reminder. Action: find the answer to a common question.
- A visitor who wants to know what happens to their data before they trust the app. Action: read what HabitTrail collects and why.

## 2. Site map

```
Home
  -> Support
  -> Privacy
Support
  -> Home
Privacy
  -> Home
```

Home is the only page a visitor is likely to land on first, so it links out to both other pages. Support and Privacy each link back to Home, since neither one needs to link to the other.

## 3. Required content per page

- **Home**: Introduces HabitTrail, lists its main features, and gives a visitor a clear next step, such as a link to download the app.
- **Support**: Answers the questions a new user is most likely to have, such as how to set a reminder or reset a streak.
- **Privacy**: States plainly what data HabitTrail collects, why it collects it, and how a user can ask for it to be deleted.

## 4. Success criteria per page

- **Home**: A first-time visitor can explain, in one sentence, what HabitTrail does.
- **Support**: A visitor with a common question can find the answer without leaving the page.
- **Privacy**: A visitor can find what data is collected and how to request deletion without searching.
