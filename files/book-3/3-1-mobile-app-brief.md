# HabitTrail

## User and repeated task

Priya, who wants to read for ten minutes every day and keeps forgetting whether she already did it.

## Smallest useful version

Add a habit, mark it done for today, and see how she's doing.

## Non-goals

- User accounts or sign-in
- Syncing habits between devices
- Social features, such as sharing progress with friends
- Reminders more complex than a single daily time

## Screens

- **Habits**: a list of the user's habits, showing which ones are done today
- **Add Habit**: a form for creating a new habit
- **Habit Detail**: a single habit's history and streak, reached by tapping it from the list, with options to edit or delete it

## Stored data

Each habit needs:

- A name
- The date it was created
- A record of which days it was marked complete
